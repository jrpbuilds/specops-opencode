# Security Policy

## Supported Versions

Only the latest published version of `@jrpbuilds/specops-opencode` receives
security fixes. Older releases are not backported.

| Version | Supported |
| ------- | --------- |
| Latest  | ✓ |
| Older   | ❌ |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, use GitHub's private vulnerability reporting through the repository's
**Security** tab.

When possible, include:

- the affected version
- steps to reproduce the issue
- the expected and actual behaviour
- the potential impact
- any suggested mitigation or fix

## Scope

This policy covers the `@jrpbuilds/specops-opencode` package and this repository.

Issues originating solely from OpenCode, OpenSpec, or other upstream dependencies
should be reported to those projects instead.
